# Henkilökohtaiset opintopolut

Henkilökohtaiset opintopolut · BC Helsinki. Tämä repo sisältää opettajan rakentaman staattisen sivuston, joka julkaistaan GitHub Pagesilla.

- Sivuilla ei ole opiskelijoiden nimiä. Polut tunnistetaan pseudonyymeillä.
- Sivut eivät ole hakukoneiden indeksoitavissa (`noindex`, `robots.txt`).
- Jokaisella polulla on oma, arvaamaton osoite. Osoite annetaan vain kyseiselle opiskelijalle.

Sivusto on tuotettu automaattisesti, eikä sitä muokata käsin.

Kansio `demo/` on Viikkopolun demo keksityllä aineistolla (esittely ja esimerkkipolku), ei oikean opiskelijan polku. Se tuotetaan viikkopolku-repon komennolla `scripts/rakenna_demo.py --erillinen`, eikä sitä muokata käsin.
